# Network Resilience Analyzer

Python course project that models a communication network, identifies important devices using graph centrality, and compares random device failures with targeted removals.

## Files

- `outputs/network_resilience_analyzer.ipynb` — executable notebook with analysis, printed results, and plots.
- `outputs/network_resilience_project_report.pdf` — project report with problem statement, methodology, implementation plan, results, conclusions, and limitations.

## Requirements

Python 3, NetworkX, and Matplotlib. Run the notebook from top to bottom. It builds its sample topology in code and does not require an external dataset.
